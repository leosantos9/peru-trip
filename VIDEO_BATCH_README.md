# Add this seven-video batch

This project uses two small ZIP downloads so Windows can extract them reliably.

1. Extract the project ZIP. It creates a `peru-trip` folder.
2. Extract the companion video ZIP into the same parent folder. Allow it to merge its `peru-trip/content/videos` folder with the project folder.
3. Open `peru-trip` and double-click `build.bat`. The build creates `dist/` for GitHub Pages/Hostinger and `dist-offline/peru-journal.html` for offline sharing.
4. Double-click `preview.bat` to review the site before committing and pushing.

The video ZIP contains only the seven optimized clips and their seven poster frames. The original camera files should remain in your personal backup.
